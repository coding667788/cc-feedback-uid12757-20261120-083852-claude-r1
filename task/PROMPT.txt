实现本地会话策略服务。每组织有完整的左闭右开策略时间线，定义最大绝对时长、空闲期限、敏感动作最低等级；组织维护受信非递减业务时钟。相邻策略生效之间即便没有请求，也必须计算会话首次变得不可用的时刻；后续放宽不复活。普通成功操作更新最后活动时刻，认证升级更新等级且同样必须通过当前时段校验。

允许按完整快照追加未来策略，也允许撤回尚未生效的版本，禁止编辑已经经过的时间段。用 SQLite 原子提交策略、会话变更和幂等回执，以事务内时钟解释同时发生的到期、策略边界和活动。测试两个进程在缩短期限切换处争用、收紧与放宽之间没有动作、同 ID 新会话代数、真实终止自建进程于提交前后。用独立的逐秒小时间模型核对首个失效时刻。

时间为整数秒，时刻等于期限则到期。策略边界先采用该秒生效的政策并检查期限，随后才按录入顺序处理同秒操作。

并发测试用同步点固定先后。只终止本题启动的测试子进程。请求 ID 在租户内唯一，同 ID 同参数返回已持久化的第一次结果，异参拒绝。未提交中断以重启后的数据库状态判断，业务失败的回执应与业务状态区分。

在 Windows 原生 Python 3.12 上完成，仅用标准库和 CPU。所有输入自行合成，在本地测试目录离线运行。交付源码、README、可重放的 cases.json、自动化测试。统一提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v，README 写明输入结构、错误码、边界示例和实测结果。预期值须由独立判定或明确断言得出，测试不得从被测实现反推期望结果。
